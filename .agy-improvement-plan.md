## 1. Executive Summary & Audit Findings

An exhaustive audit of the `ai-news-public` codebase was conducted, covering:
- Backend translation script (`scripts/update-ai-news.py`)
- Live RSS feed endpoints from `https://www.agenticbrew.ai/feed/*.xml`
- Google Translate API communication layer
- Generated data file (`ai-news.json`, 18 existing items across 10 sections)
- Frontend rendering, accessibility, and typography (`index.html`)
- Automation workflow (`.github/workflows/update-ai-news.yml`)

The audit revealed critical flaws:
1. **Google Translate HTTP 429 blocking:** Google's `translate.googleapis.com` endpoint rejects Python `urllib` HTTP/1.1 requests to `client=gtx` with `429 Too Many Requests`. Consequently, **100% of new translation calls currently fail and silently fall back to English** or empty strings.
2. **Linguistic and terminology errors in Georgian translations:** Several domain terms are severely mistranslated into Georgian ("Superintelligence" → "სუპერდაზვერვა" / CIA intelligence; "Prompt guardrail" → "სწრაფი დამცავი ღერძი" / quick axle; "1.46m params" → "1.46 მმ" / millimeters; "acting" → "მსახიობობას" / theatrical acting).
3. **URL and markdown corruption:** Google Translate corrupts URLs and markdown link syntax (`[text](url)`), converting URL query parameters into broken gibberish (`utm_medium=event_contm_camutopa`).
4. **Redundant translation requests:** Every run translates fetched items before checking if they already exist in the 7-day retention ledger, wasting API quotas.
5. **Frontend UX and accessibility gaps:** Grammatical mistakes in UI labels ("ქართულ ტექსტის კოპირება", "სულ loaded"), broken Deep Dive section behavior when filters are selected, unformatted UTC date strings, and lack of keyboard accessibility.

## 2. Real Problems Found with Concrete Evidence

### Problem 1: Google Translate API HTTP 429 & Silent English Fallback
- **Evidence:** Running the translate function via Python `urllib.request` produces:
  ```
  [03:58:02] WARN: translate() failed, using fallback: HTTP Error 429: Too Many Requests
  ```
  Testing HTTP versions and clients confirmed:
  - `client=gtx` over HTTP/1.1: `HTTP/1.1 429 Too Many Requests` (Google anti-bot block).
  - `client=dict-chrome-ex`, `client=it`, `client=at`: `HTTP/1.1 200 OK` (immediately succeeds).
  - Any client over HTTP/2 (via curl): `HTTP/2 200 OK`.
- **Root Cause:** Hardcoded `TRANSLATE_URL` using `client=gtx` over Python's HTTP/1.1 client triggers Google's bot detection. Because the script catches this and falls back to `fallback=title_en`, all newly fetched items revert to English without alerting the operator.

  - **Item #14 (blog):** `I’m building a runtime governance layer for AI agents — not another prompt guardrail`

    *Issue:* Truncation at character limit cuts mathematical expressions and words mid-token.

### Problem 3: Inefficient Re-translation of Cached Entries
- **Evidence:** In `process_feed()`:
  ```python
  title_ka = translate(title_en, 180, fallback=title_en)
  excerpt_ka = translate(excerpt_en, 480, fallback=excerpt_en)
  description_ka = translate(desc_en, 1300, fallback=desc_en)
  ```
  This is executed for every fetched item *before* checking whether the item already exists in `existing_sections[feed]`.
- **Impact:** Translates 3×N strings on every run even if 90% of items are already stored with valid Georgian text, increasing latency and rate-limit risks.

### Problem 4: Upstream Feed Status (github & product_hunt)
- **Evidence:** Live testing confirmed:
  - `news`, `twitter`, `reddit`, `youtube`, `skill`, `blog`, `paper`, `event`: HTTP 200, valid items (5 to 100 items each).
  - `github` and `product_hunt`: HTTP 200, valid RSS 2.0 XML channel, but currently contain 0 `<item>` elements.
- **Impact:** Feed chips for `github` and `product_hunt` show `(0)`. When clicked, UI shows empty sections. The script must retain existing items from previous days rather than clearing them.

### Problem 5: Frontend UI, Grammar, and Accessibility Issues
- **Evidence in `index.html`:**
  - Line 405: `copySummary.textContent = 'ქართულ ტექსტის კოპირება'` → Grammatical error (should be `ქართული ტექსტის კოპირება`).
  - Line 251: `<div class="k">სულ loaded</div>` → Untranslated English slang.
  - Line 249: `<div class="k">featured</div>` → English label in Georgian layout.
  - Line 428: `<a class="readmore" href="javascript:void(0)">სრულად წაიკითხე →</a>` → Non-semantic, inaccessible `javascript:void(0)`.
  - Line 355: `const item = state.featured.find(matches) || state.featured.find(Boolean);` → When a category like "paper" or "blog" is selected, Deep Dive falls back to an unrelated featured item (from news/twitter/reddit).
  - Line 280: `თუ გინდა, შემდეგში ამ გვერდს ავტომატურ daily refresh-ს... დავუმატებ` → Outdated developer note from initial scaffolding.
  - Raw date strings: `Sun, 06 Sep 2026 18:08:55 GMT` rendered directly without Georgian localization.
  - Cards lack keyboard navigation (`tabindex="0"`, Enter key handler).

## 3. Prioritized Improvement Plan

### Priority 1: Fix Translation Reliability & Client Fallback (Root Cause)
- **Target:** `scripts/update-ai-news.py`
- **Actions:**
  1. Change default client to `dict-chrome-ex`, which is reliably serviced over HTTP/1.1 by Google Translate.
  2. Implement client rotation / multi-tier fallback: `['dict-chrome-ex', 'it', 'at', 'gtx']`.
  3. Support fallback to local `curl` (HTTP/2) if available via `shutil.which('curl')`, ensuring zero-dependency standard library compliance while unlocking HTTP/2.
  4. Ensure `translate()` logs explicit warnings with HTTP status codes so failures are never silent.

### Priority 2: Improve Translation Pre-processing & Terminology Post-processing
- **Target:** `scripts/update-ai-news.py`
- **Actions:**
  1. **URL & Markdown Protection:** Pre-process text to replace URLs (`https?://\S+`) and code snippets with unique indexed tokens (e.g. `__URL_0__`), translate the text, and restore the exact URLs afterwards.
  2. **Clean HTML/Entities:** Strip raw HTML tags (`<p>`, `<br>`, `<a>`) or normalize whitespace before translating.
  3. **Word-Boundary Truncation:** Truncate on clean word boundaries (`.rsplit(' ', 1)[0] + '…'`) instead of slicing arbitrary character indices.
  4. **AI Glossary Normalization:** Post-process known machine translation anomalies:
     - Replace "სუპერდაზვერვა" / "სუპერდაზვერვის" → "სუპერინტელექტი" / "სუპერინტელექტის".
     - Replace "სწრაფი დამცავი ღერძი" → "პრომპტების უსაფრთხოების სისტემა" / "გარდრეილი".
     - Replace "მსახიობობას" in agent execution contexts → "დამოუკიდებელ მოქმედებას".
     - Replace "ბოლო თარგმანის მაჩვენებელი" → "თარგმანის ბოლო ბენჩმარკი".
     - Replace "უნარი ვეტერი" → "უნარების ვერიფიკატორი".
     - Fix metric representations like `1.46 მმ` in AI model descriptions → `1.46M`.

### Priority 3: Translation Deduplication & Cache Optimization
- **Target:** `scripts/update-ai-news.py`
- **Actions:**
  1. In `process_feed()`, check if `item['uid']` already exists in `existing_sections[feed]` and already contains valid Georgian translations.
  2. If already translated, reuse existing Georgian fields (`title_ka`, `excerpt_ka`, `description_ka`) and skip redundant API calls.
  3. Adjust feed fetch limits reasonably (e.g. 4-5 items per feed) so fresh news isn't missed while maintaining execution speed under 25 seconds.

### Priority 4: Frontend UI, Georgian Polish & Accessibility
- **Target:** `index.html`
- **Actions:**
  1. **Linguistic Polish:**
     - `ქართულ ტექსტის კოპირება` → `ქართული ტექსტის კოპირება`.
     - `სულ loaded` → `სულ სიახლე`.
     - `featured` → `რჩეული`.
     - `10 feed` → `10 წყარო`.
     - `სრულად წაიკითხე →` → `დაწვრილებით →`.
     - Update footer to reflect live automated daily refresh at 08:00 (Tbilisi time).
  2. **Filter & Deep Dive Alignment:**
     - Update `renderDeepDive()` so that if a filter is active, it picks the top item from the active filter (`(state.sections[state.filter] || [])[0]`), falling back to featured only when viewing "all".
  3. **Date Localization:**
     - Format `pub_date` into clean, localized Georgian date and time (`d MMMM, yyyy, HH:mm`) instead of raw UTC strings.
  4. **Accessibility:**
     - Make cards keyboard accessible with `tabindex="0"` and `keydown` event listener for Enter/Space.
     - Replace `href="javascript:void(0)"` with semantic accessible button or link behavior.

### Priority 5: Full Regeneration & Local Verification
- **Actions:**
  1. Run `python3 scripts/update-ai-news.py` to regenerate `ai-news.json` with all improvements.
  2. Verify exit code 0 and inspect the generated JSON to verify high translation quality and absence of English fallbacks.
  3. Run local HTTP server (`python3 -m http.server 8000`), perform headless curl/browser validation, and inspect output.
  4. Stage intentionally modified files, commit with clear message, and push to `origin main`.
